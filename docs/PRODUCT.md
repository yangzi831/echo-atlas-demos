# Echo Atlas Product Notes

## 项目定位

Echo Atlas / 城市回声档案是一张连接城市、声音和时间的 AI 声景地图。它不把城市简化成景点、路线或消费推荐，而是用声音保留含混、记忆和想象空间。

第一阶段聚焦上海，目标是在黑客松现场展示一个结构完整、视觉完成度高、可运行的前端原型。

## 核心体验

用户在地图上看见不同年代的声音节点。节点不是普通图钉，而是像声波残留一样呼吸。用户可以按时间进入城市，也可以让 Echo Agent 策展一条轻量的声音漫游路线。

## 第一阶段范围

- 上海地图与艺术化 fallback
- mock 声音节点
- 时间丝带筛选
- 声音详情面板
- Echo Agent mock 路线
- 上传声音原型流程

暂不包含：

- 登录
- 社区系统
- 支付
- Supabase
- Gemini
- 真实音频上传与持久化

## 声音来源类型

- `user_recording`：用户现场录音。
- `authentic_archive`：真实历史档案。
- `artistic_reconstruction`：艺术化重构或未来档案推演。
